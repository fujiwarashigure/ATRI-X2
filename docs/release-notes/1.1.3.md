# ATRI-X 1.1.3 发行说明

当前最新版本：**`1.1.3`**（正式发行版）：新增**科研研究助理**——随包分发的研究引擎（`research_pack/`，38 个模块约 8.7k 行、纯标准库）与 15 个原创 AgentSkill（12 个 `risk="low"` 硬工具 + 3 个协议技能），把「检索 → 筛选 → 核验 → 大纲 → 引用 → 写作 → 质检 → 评审 → 导出」做成确定性流水线：检索去重、PRISMA 计数、DOI 反查（Crossref / DataCite）、APA / GB-T 7714 引用、正文结构契约、六维固定公式评分全部由引擎代码完成，模型只负责判断与表达，**换 LLM 时流程与判定标准不变**。首次启动自动把引擎与技能装进配置目录（幂等、按内容摘要升级、尊重 `atri-research/install.py` 的 venv 版外部安装），**安装版 / 便携版开箱即用、不需要系统 Python**；源码树用户按 [docs/research.md](../research.md) 安装。新增 `/research` 只读命令（`status` / `<运行id>` / `env` / `open`，普通成员可用）与桌面端第 13 个选项卡「研究」（运行列表 + 产物树 + 打开报告/导出目录）。**1.1.3 修订（同日）**补齐人设卡「导入 / 启用」：聊天里 `character_import` 一步把粘贴文本建卡、`persona_control` 让成员自助开关**专属人设**（按人持久、只影响本人、关闭恢复默认 `SOUL.md`）、`character_activate` 把角色卡设为全局人设并可回滚（仅超管）；桌面端「人设卡」页新增导入文件 / 粘贴导入 / 导出（ZIP 含图片）与 SOUL 从卡载入，新增第 14 页「权限」登记各平台超级管理员（QQ 填 QQ 号）并调工具轮次 / 成员建卡开关；另加**私聊回声保护**：`[自动回复]` 等客户端自动应答与同一人连续复读完全相同文本不再唤醒模型，避免与对方的自动回复互相刷屏；**上线通知**从 `hooks.toml` 搬到 `app.toml [connect_notice]`，私聊（超管）与群聊（`groups` 里的 QQ 群号）变成两个独立开关，桌面端「在线」页可直接勾选。新增 `docs/research.md` 与 `research_pack/README.md`；引擎与技能为原创实现，不含上游 `academic-research-skills` 的任何文本或代码（原创性核查见发行说明与 `LEGAL.md`）。1.1.2 的群友人设接入与 1.1.1 的两处修复全部保留；**不改现有配置格式 / 工具 schema / 会话与数据库格式**，配置与会话数据**向后兼容**；完整变更见 [CHANGELOG.md](../../CHANGELOG.md)。

交付物：`ATRI-X-1.1.3-setup.exe`、`ATRI-X-1.1.3-portable-win64.zip`、源码归档 `ATRI-X-1.1.3-repo.zip` / `.tar.gz`（1229 条目）；尺寸与 SHA-256 见该版发行库的 `SHA256SUMS-1.1.3.txt`、发行说明与自检报告。发布后对应 tag 为 `v1.1.3`。
