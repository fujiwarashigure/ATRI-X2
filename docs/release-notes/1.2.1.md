# ATRI-X 1.2.1

2026-11-06 发布版本（GitHub Release `v1.2.1`）。本次为 1.2.0 之后的全仓审计修复批次，并在第二次冻结中
重做了桌面界面（Frutiger Aero），重新冻结源码归档、便携版与安装版三类产物。

- 发布入口：<https://github.com/fujiwarashigure/ATRI-X2/releases/tag/v1.2.1>；附件含安装包、
  便携版、源码归档与 `SHA256SUMS-1.2.1.txt`。
- 源码归档重打包时移除了构建机的 DSH 运行期残留（`dsh/home` 下的匿名用户 ID 与 profile 状态）；
  全仓脱敏扫描（源码树 + 源码包）0 命中。

## 桌面界面（第二次冻结：Frutiger Aero）

- 整体换成玻璃 / 水光 / 天空风格：浅青玻璃面板、渐变页头、气泡与高光、天蓝色滚动条与
  玻璃质感按钮；左侧导航是深青渐变栏，顶部是带品牌字的玻璃徽标。
- 页头用 Canvas 现画（渐变 + 高光 + 气泡 + ATRI 角色图），窗口缩放不会出现拼接缝；标题 /
  连接状态 / 「重新连接」放在玻璃板上，随页切换。
- 聊天欢迎页换成 Aero 风格壁纸（天空 / 云 / 气泡 / 草坡 / 水面 + ATRI 角色）；有聊天内容
  后仍自动隐藏壁纸，保证正文可读。
- **导航合并**：顶部那条 18 页标签栏彻底去掉；六个分组（对话 / 研究与知识 / 角色与记忆 /
  模型与工具 / 连接与平台 / 系统设置）下直接列出页面，页内子选项卡（LLM Provider /
  上下文窗口 / 搜索服务 / 抓取服务 / 工具参数 / 工具进度预览 / 内容安全各子页 …）也合并进
  同一棵树；切换页面或子页时左侧自动展开并高亮，不再有第二套下拉选择器。
- **布局可达性**：表单页（模型 / 平台 / 在线 / 群友）整页可纵向滚动，页内子页（工具进度预览 /
  生图档案 / 内容安全词表）也能滚；底部「保存 / 重新载入 / 重启后台服务」按钮条改为先占位
  再让正文吃剩余高度，**保存类按钮永远固定在最下面**；内容装得下时滚动条自动隐藏。最小窗口
  从 1100×700 调整为 1180×700，人设卡等左右分栏页不再横向裁切。
- 验证：1200×720、1366×768、1920×1080 三种尺寸逐页截图 + 控件越界审计，18 个主页面与页内
  子页均无“滚不到底”的控件；全量测试与 11 项门禁全绿。
- 新壁纸与页头角色图随包放在 `atri_x/gui/brand/`；缺失时自动回退旧素材，素材全缺也只是
  “没有背景”，不影响启动。

## 界面修复（第一次冻结）

- 标签选择对话框改为「确认即替换为对话框完整选择集」：取消勾选的已登记标签不会再加回；
  搜索过滤前先收集勾选变化，被过滤隐藏的选择不会丢失；未登记的手写标签由对话框保留。
- 标签名输入框在改名功能落地前设为只读，避免「可编辑但保存不生效」的静默失败。
- 群友档案页图库条目权重为 `0` 时回显 `0`（不再回落成 `1.0`，避免再点「应用」改掉用户值）。
- GUI 自检在界面构造、`withdraw` 或断言失败时也会销毁已创建的窗口，不再残留 Tk 根窗口。
- 角色素材来源与权利说明见 [壁纸说明](../../atri_x/gui/brand/WALLPAPER-LICENSE.md)。素材不属于 Apache-2.0 授权范围，对外再分发须确认权利。

## 行为修复

- **画师库事务**：画师条目与画师串组合的新增/更新/删除在落盘失败时恢复整库快照（记录与
  库版本号一起回滚），不会再出现「报错但内存已改」；非超级管理员对画师条目的标签写入一律
  拒绝（创建与更新两条路径一致）。
- **模型配置**：`Provider` 改名在任何写入前直接拒绝并说明原因（不再写坏配置）；上下文窗口
  拒绝 `NaN`/`inf` 等非有限值；YAML 字符串统一加引号并拒绝控制字符，避免模型名/ID 被解析成
  其他类型；时间页默认值测试改为对照配置层数据类。
- **平台调用协议**：批量平台调用中的任务取消原样传播并停止后续调用（普通失败仍携带已完成
  结果）；整数参数限定为有符号 64 位并只接受 ASCII 十进制，非有限/非整数浮点返回「不是
  整数」而不是抛转换异常；外部事件里的工具名单、Atriwisp 标签必须是字符串，工具超时拒绝
  布尔与超 int64 值。
- **记忆命令**：`/forget resident clear` 与 `core`/`all` 一样必须先加 `--confirm`。
- **研究引擎（随包 research_pack 0.2.0）**：`research_verify` 的 `suggest_doi=false` 现在真正
  生效（缺 DOI 文献不再被发去 Crossref 反查标题）；筛选阶段「全部排除」不再被下游放大为
  「全部候选」，只有尚未筛选时才回落到全部；`pack.json` 增加可复算的清单生成器
  （`scripts/gen_research_pack.py`）。
- 沙箱镜像版本继续使用既有 1.2.0 镜像契约；应用版本与包元数据统一为 1.2.1。

## 便携版与安装版

- 便携打包前同样复查内置协议端脱敏状态，残留 OneBot/WebUI 运行期文件时拒绝出包。
- 便携/调试启动器与便携自检显式清空继承的 `ATRIX_HOME`，保证便携数据只落在解压目录，
  不写入真实用户数据目录。
- 重新冻结程序，不复用旧版应用可执行文件；发布源码排除 Git 历史、本机运行时输入、用户
  数据、缓存、日志、密钥和构建残留。
- 内置协议端按既有脱敏流程重新整理，不包含来源机登录状态与令牌。
- 第二次冻结（含 Frutiger Aero 界面）按同一脱敏流程重新打包源码归档 / 便携版 / 安装版，
  版本号仍为 1.2.1。

## 已知限制（未在本次修复）

- 随包 draw.io 分支脚本：`ATRIX_DRAWIO` 环境变量按文件存在性解析可执行文件、读取 `.drawio`
  时解压无上限、部分渲染子进程无超时、输出路径未强制约束在 `out/`。这些脚本只通过沙箱内
  超级管理员可用的 `drawio` 工具触达，不是普通用户路径。
- 研究引擎：导出不强制流程门禁、旧 QA/审核结果不会因草稿改动失效、缺大纲时 compose 偏宽、
  arXiv 使用明文 HTTP 且无响应大小上限、缓存 TTL=0 不失效且保留检索式/邮箱明文、RunStore
  的路径约束不抗链接、HTML 链接未过滤 scheme、PDF 文本映射与重名覆盖等。
- 玻璃质感是用「渐变 + 高光 + 纯色玻璃板」在 Tk 里模拟的：没有真正的窗口级模糊 /
  亚克力透明，窗口标题栏仍是系统原生样式。
- 安装包未做代码签名，Windows SmartScreen 可能提示；卸载器按进程名结束 ATRI-X，本次不执行
  卸载自检，避免误停其他安装。
- 真实模型调用、QQ 账号登录、真实 Docker 容器端到端、SmartScreen 信任与跨机器兼容性仍未
  验证；测试中的模拟 Docker 失败输出属于故障分支用例，不代表真实容器验收。

最终验证结果与 SHA-256 以发行目录中的本次验收报告和校验清单为准；不沿用旧版报告结论。
