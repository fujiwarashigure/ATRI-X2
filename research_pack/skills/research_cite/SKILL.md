# research_cite

格式化的唯一出口。**正文引用键只从这里来。**

## 参数

| 参数 | 说明 |
| --- | --- |
| `run` | 运行 id（必填） |
| `style` | `gbt7714`（GB/T 7714-2015 顺序编码制）或 `apa7`；缺省用运行记录的样式 |

## 返回

- `count`：条目数；
- `sample`：前三条，用来快速检查格式；
- `unused_in_text`：参考文献里未被正文引用的条数（没写正文时为 0 属正常）；
- 完整映射在 `references.json` 的 `by_cite_key`：`cite_key` → `work_key`。

## 引用键规则

`第一作者姓 + 年份`，小写 ASCII；同作者同年多篇自动加 `a`/`b`；
中文姓名取前三字。例如 `smith2021`、`张2023`、`wang2024a`。

## 两种样式的差异

- **GB/T 7714**：`[1] 作者. 题名[J]. 刊名, 年, 卷(期): 页. DOI: ...`，
  编号按正文出现顺序（先 `research_cite` 再写作时按引用顺序重排一次）；
- **APA 7**：`Author, A. (2021). Title. *Venue*, *vol*(issue), pages. https://doi.org/...`，
  按第一作者字母序，正文用 `(Author, 2021)` 风格——但本工具统一用 `[@key]` 标记，
  最终排版由用户/期刊模板决定。

## 注意

- 标题按原文大小写保留（不强转句首大写，避免破坏专有名词）；工具会在 `notes` 里声明；
- 会议论文/书籍章节按近似格式输出，目标期刊有特殊要求时需人工微调；
- 没有 DOI 的条目会退到 arXiv/PubMed/OpenAlex 定位符，保证每条都有可核查地址；
- 写作过程中正文变了要重新调用本工具，让 `unused_in_text` 与编号保持最新。
